# Python Network Sniffer

A Python-based network sniffer that captures, parses, filters, and analyzes live network traffic using Scapy.

## Features

- Live Packet Capture
- TCP/UDP/ICMP Detection
- Packet Analysis
- Traffic Statistics
- CSV Export
- PCAP Export

## Technologies

- Python
- Scapy
- Pandas
- Matplotlib
- Colorama
